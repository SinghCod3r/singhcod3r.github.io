# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 15 App Router, React, Tailwind-compatible CSS, GSAP/ScrollTrigger, Lenis Smooth Scroll, static export for GitHub Pages.

## Users

Engineers, open-source maintainers, recruiters, and collaborators evaluating Ayush Singh's systems work and public contributions.

## Product Purpose

An experience-led portfolio that makes Ayush's upstream engineering work, selected projects, speaking, and writing easy to understand and easy to continue exploring. Success is a visitor finding a credible proof point and a way to connect within the first few minutes.

## Positioning

A portfolio grounded in real upstream Linux and OpenPrinting maintenance rather than generic software-project claims.

## Operating Context

Visitors arrive from GitHub, LinkedIn, or a shared portfolio link on desktop and mobile. The site must work as a static export on GitHub Pages.

## Capabilities and Constraints

- Single-page portfolio with anchored sections and animated transitions between them.
- Resume facts are the source of truth for claims, dates, projects, and achievements.
- Supplied image and project screenshots are available in the project root.
- No invented testimonials, metrics, or client claims.
- Motion must degrade for reduced-motion preferences.

## Brand Commitments

- Name: SinghCod3r / Ayush Singh.
- Voice: concise, human, calm, technically credible.
- Avoid terminal-style brackets, slash-heavy labels, and robotic telemetry.
- OpenPrinting should be a visible thread through the experience.

## Product Principles

1. Let real upstream work lead.
2. Keep the copy airy and specific.
3. Use motion to connect sections, not to distract from reading.
4. Make every proof point reachable in one gesture.

## Accessibility & Inclusion

Use semantic landmarks, visible keyboard focus, readable contrast, alt text, reduced-motion fallbacks, and touch-friendly targets.
