# SinghCod3r Portfolio

[![Deploy Next.js to GitHub Pages](https://github.com/SinghCod3r/singhcod3r.github.io/actions/workflows/deploy.yml/badge.svg)](https://github.com/SinghCod3r/singhcod3r.github.io/actions/workflows/deploy.yml)

Personal portfolio and open-source engineering showcase for **Ayush Singh** ([@SinghCod3r](https://github.com/SinghCod3r)).

Live deployment: [https://singhcod3r.github.io](https://singhcod3r.github.io)

---

## ⚡ Tech Stack & Architecture

- **Framework**: Next.js 15 (App Router, Static Export `output: export`)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Glassmorphism
- **Motion & Kinetic Effects**: GSAP 3, Lenis Smooth Scroll
- **Deployment**: GitHub Pages via GitHub Actions

---

## 🛠️ Local Development

```bash
# Clone repository
git clone https://github.com/SinghCod3r/singhcod3r.github.io.git
cd singhcod3r.github.io

# Install dependencies
npm ci

# Start development server
npm run dev

# Build static export
npm run build
```
